# hsd-configurator

Конфигуратор скоростных ворот **SDA** (база Lefast HSR1000) для DOORHAN SIAM:
заказ → расчёт конструкции → спецификация → CSV сборки для Zoho Inventory.

Ядро — чистый JavaScript без зависимостей. Один и тот же код будет работать на сервере
Zoho Catalyst, в тестах и в браузере (предпросмотр в форме заказа).

## Как устроено

```
catalogs/hsr/     каталоги в JSON: артикулы Zoho, направляющие, боковины, моторы, раскладки, правила полотна
core/             общее для всех изделий: единицы, сообщения, override, CSV сборок Zoho, загрузка каталогов
products/hsr/     расчёт SDA: input → frame → curtain (+layout) → drive → spec
tests/            тесты на реальных заказах (tests/orders/*.json) и на правилах из журнала решений
scripts/          проверка каталогов, расчёт заказа из файла
```

Объект заказа — схема v1 (`order / opening / options / calc / spec`, поле `productType`).
Вход — `order`, `opening`, `options` (ручные отступления в `options.overrides` с причиной).
Выход — `calc` и `spec`, всегда пересчитываются из входа и каталогов.

## Команды

Нужен Node.js 18 или новее.

```
npm test                          # все тесты
npm run check:catalogs            # все SKU из каталогов есть в items.json
node scripts/calc-order.js tests/orders/DSO-26659.json --csv SDA-DS --date 2026-11-25
```

## Правила расчёта

Все формулы взяты из журнала решений `HSR_project_brief.md` (25.11.2026). Коротко:

| Блок | Правило |
|---|---|
| Рама | W ≤ 4000 и H ≤ 4000 → боковина S 274×234, вал φ114, верх H+470; иначе до 28 м² → M 322×284, φ140, H+520; > 28 м² не делаем. Короб W+230 (нерж. W+184), вал W+120 (W+74), направляющая H+200 ×2, балка MET50x25 ×2 длиной короб − 1 |
| Полотно | Ширина W+140 (нерж. W+105), раскрой +250. Длина = H + 200 + Hб/2 + π·D. Цепочка: 85 + 50 + Σh + 40·n. Раскрой: непрозрачная h+94, окно — плёнка h−10 и 2 полосы по 84, верхняя h+47+120 |
| Раскладка | Строка стандартных раскладок (тред 02) с наибольшей H ≤ H заказа, верхняя — остаток. «+1» делит нижнюю, «+2» нижнюю и верхнюю (пока пополам) |
| Привод | Powever A2: φ114 → 0,75 кВт; φ140 → 0,75 до 14 м², 1,5 до 28 м². Кабель (полная высота − h блока) + (W+300, если пульт на другой стороне) + 1000, докупка сверх 4/5 м |
| Спецификация | На одни ворота в единицах Zoho; разделы curtain / header / guides / drive. SDA-DS — все разделы, DUS-055 — только полотно |
| CSV | Как у секционных (`zoho_export.html`): UTF-8 BOM, CRLF, шапка в каждой строке, Mapped Quantity = на ворота × количество |

Открытые вопросы и временные решения — в `docs/open-questions.md`.
